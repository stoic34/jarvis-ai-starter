# Jarvis AI Starter Kit

Build your own personal AI assistant using Obsidian + Claude Code.

## What You Get

- A structured Obsidian vault ready for your AI to manage
- Pre-configured CLAUDE.md that gives your AI personality and capabilities
- Essential tools for email, voice memos, and document generation
- Guided onboarding that walks you through setup

## Quick Start

### 1. Download This Repo

Click the green **Code** button above → **Download ZIP**

Extract to a folder like `~/Documents/Jarvis` (Mac) or `C:\Users\YourName\Documents\Jarvis` (Windows)

### 2. Install the Prerequisites

**You'll need:**
- [Obsidian](https://obsidian.md/) (free) - Your knowledge base
- [Claude Code](https://claude.ai/code) - The AI engine
- [Git](https://git-scm.com/) - Version control (safety net)

See [docs/SETUP-MACOS.md](docs/SETUP-MACOS.md) or [docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md) for detailed installation guides.

### 3. Open in Obsidian

1. Open Obsidian
2. Click "Open folder as vault"
3. Select the `vault/` folder from this repo

### 4. Run Claude Code

Open your terminal in this folder and run:

```bash
claude
```

Your AI will guide you through the rest of the setup, including:
- Naming your assistant
- Connecting your email
- Testing all the tools
- Creating your first note

## What Can Your AI Do?

Once set up, your AI assistant can help with:

- **Email Management** - Scan, summarize, draft responses
- **Voice Memo Ingestion** - Transcribe recordings into notes
- **Document Generation** - Turn notes into professional PDFs
- **Calendar Management** - Schedule, review, block time
- **Research & Analysis** - Deep research on any topic
- **Project Tracking** - Manage tasks and initiatives
- **And much more** - See [docs/USE-CASES.md](docs/USE-CASES.md)

## Important: YOLO Mode

For the best experience, you'll want to run Claude Code in "accept edits" mode so it can work autonomously. See [docs/YOLO-MODE.md](docs/YOLO-MODE.md) for setup instructions.
