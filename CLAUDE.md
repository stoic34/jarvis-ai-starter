# CLAUDE.md

This file exists for Claude Code compatibility.

The source-of-truth instructions for this starter kit now live in `AGENTS.md` so the same assistant setup can run in Codex, Claude Code, and other AGENTS-compatible coding agents.

## Required First Step

Read `AGENTS.md` before doing any work in this repository.

Use `AGENTS.md` as the governing instruction file. If this file and `AGENTS.md` ever conflict, follow `AGENTS.md`.

## Runtime Note

Claude Code can run this starter kit, but the recommended starting runtime is Codex on macOS because it has stronger support for the current desktop-control and remote-Mac workflow.
