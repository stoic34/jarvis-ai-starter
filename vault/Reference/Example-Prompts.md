# Example Prompts

Copy-paste these prompts to get started quickly. Customize the [bracketed] parts.

---

## Email

```
Scan my inbox and tell me what needs attention today.
```

```
Find all emails from [person/company] in the last [time period].
```

```
Draft a professional email to [recipient] about [topic].
Keep it concise and friendly.
```

```
Draft a follow-up email to [person] about [previous topic].
Reference our last conversation and ask about [specific question].
```

```
Help me write a difficult email. I need to [explain situation]
but maintain a good relationship with [person].
```

---

## Calendar

```
What's on my calendar today?
```

```
What does my week look like? Any conflicts or back-to-back meetings?
```

```
Find a 2-hour block for deep work this week.
```

```
Schedule a meeting with [person] sometime next week.
Suggest a few time options.
```

## Voice & Notes

```
Transcribe my latest voice memo and extract any action items.
```

```
Process my inbox and help me decide what to do with each item.
```

```
Add to my inbox: [quick thought or task]
```

```
Create a new project note for [project name].
Start with goals and next actions.
```

---

## Research

```
Research [topic] and give me a 5-bullet summary of the key points.
```

```
I'm deciding between [option A] and [option B].
What are the pros and cons of each?
```

```
What are the latest developments in [industry/technology]?
Focus on [specific aspect].
```

```
I found this article/research: [paste or link].
Summarize the key insights and what I should do about it.
```

## Documents

```
Turn these notes into a professional one-page PDF:
[paste your notes]
```

```
Draft a proposal for [project/initiative].
Include: overview, goals, approach, and timeline.
```

```
Create a meeting agenda for [meeting topic].
Attendees: [names]. Duration: [time].
```

```
Format this as a professional memo:
[paste content]
```

## Tutoring & Learning

```
Create a 10-question practice test on [subject] at [grade/difficulty level].
Mix question types: multiple choice, short answer, and problem-solving.
```

```
Grade this test and identify which concepts need more work:
[paste answers or describe responses]
```

```
Create study notes for [topic] aimed at [audience/level].
Include key concepts, examples, and common mistakes to avoid.
```

```
I'm trying to learn [topic]. Create a learning plan with
milestones and practice exercises.
```

## Health & Wellness

```
Review this supplement stack for interactions and timing:
[list supplements]
```

```
Here are my blood work results: [paste or describe].
What values are outside optimal ranges and what might help?
```

```
Help me design a [workout/sleep/nutrition] protocol for [goal].
Consider [constraints/preferences].
```

## Legal & Contracts

```
Review this contract and flag any concerning terms:
[paste contract or key sections]
```

```
What are the key obligations and deadlines in this agreement?
```

```
I'm negotiating [type of deal]. What questions should I be asking?
What terms are typically negotiable?
```

```
Compare these two contract versions and highlight the differences:
Version 1: [paste]
Version 2: [paste]
```

## Project Management

```
What are my active projects? Which ones need attention?
```

```
Update [project name] with today's progress:
- Completed: [what you did]
- Blocked on: [any blockers]
- Next: [next step]
```

```
Create a project plan for [initiative].
Break it into phases with milestones.
```

```
I've been procrastinating on [project].
Help me identify the real next action and get started.
```
