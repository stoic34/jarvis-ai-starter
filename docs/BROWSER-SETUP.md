# Browser Setup

This is now a compatibility note.

For the recommended Codex-first setup, use [02-CHROME-EXTENSION.md](02-CHROME-EXTENSION.md), which covers Codex Desktop browser workflows and computer-control workflows.

## Current Recommendation

Use Codex Desktop on Mac for browser and desktop automation.

Launch:

```bash
codex app
```

Then ask:

> "Inspect what browser or desktop-control tools are available in this Codex session."

## Legacy Claude for Chrome

If you are intentionally using Claude Code, Claude for Chrome may still be useful.

Keep that as a legacy path:

- Use `CLAUDE.md`
- Follow Anthropic's current Claude for Chrome setup
- Treat `.claude/` as Claude-specific support material

Do not make Claude for Chrome the default path for new starter-kit users.
